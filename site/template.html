// a nerd lab experiment · unofficial

UN data in Python, without the guessing.

Type a country's name, get a table with its source on every row. undata is a Python package for the UN System Data Commons, which holds statistics from 26 UN System entities, and it is written for colleagues who need numbers for a report, not a course in APIs.

pip install undata

Everything on this page is real. Each use case below is a script in examples/. The output, the charts and the sentence for your report are what those scripts produced against the live platform on , and the same scripts run again every night.

// 03 — functions

Everything on one screen

Wherever a function asks for countries you can write names the way you would in an email ("Viet Nam", "Vietnam", "VNM"), a list of them, or a region such as "Southern Asia" or "Africa". Every function explains itself: help(un.get), and the API reference documents every parameter.

functionwhat it does
un.search("words")Find indicators by what they measure: one row per indicator, with how many places and years have data.
un.about(indicator)What an indicator is, whose it is, its unit, its years, and its SDG metadata.
un.get(indicator, countries, years)The numbers: one row per country and year. by="sex" for a breakdown, wide=True for one column per indicator.
un.latest(indicator, countries)
un.coverage(table)		Each country's most recent value. within=10 keeps only the past ten years and names who is older; coverage says who has what.
un.totals(indicator, ["World", "LDCs"])The official figure for a region or group, as the agency published it.
un.change(indicator, countries, 2015, 2023)Before, after, the difference and the percentage change.
un.compare({"a": id1, "b": id2}, countries)Indicators side by side, with who has which spelled out.
un.countries(region)
un.regions()		The UN M49 list: official names, M49 regions, and the current LDC, LLDC and SIDS groups.
un.sdg.goals()
un.sdg.targets(16)
un.sdg.indicators("16.1")
un.sdg.series("16.1.2")		Walk from an SDG goal down to indicators you can fetch. SDG numbers like "3.1.1" also work directly.
un.progress(indicator, countries, better="lower", target=70)On track for 2030? The UN Statistics Division's progress method, country by country, with the five SDG Report categories.
un.profile(country, indicators)
un.gap(indicator, countries, by="sex")		One country beside its region and the world; the gap between two groups in the same year.
un.trend(...)
un.benchmark(indicator)
un.availability(...)		Change since 2015; UN groups side by side; which countries report what, and how recently.
un.describe(table)
un.chart(table)		Sentences for a report, worked out from the numbers. A publication-ready chart picked to fit the table (bars, lines, small multiples, a tile map, a progress chart and more) with its source. interactive=True for hover and zoom.
un.style()
un.palette()		Give your own matplotlib and seaborn charts the same clean, colour-blind-safe look.
un.save(table, "file.xlsx")
un.cite(table)		Excel or CSV with sources; citations for a report.

// 04 — what it does for you

The careful parts are built in

Each of these was found by calling the live platform, and each is checked by a test that runs every night.

  • It never guesses a place.data.un.org's search box answers a question about "Bengal" with figures for the United States. undata stops and says it does not know "Bengal".
  • Gaps are named, never zero.Countries without data are listed in a warning and on their own Excel sheet, never charted as zeros.
  • UN names in, UN names out.Tables say Türkiye, Viet Nam and Côte d'Ivoire, ready for a UN document, whatever spelling you typed.
  • The source is on every row.The same statistic can come from several agencies with different numbers. The source column says whose you have.
  • Mixed years are flagged."Latest" means each country's own latest year. When those differ, a warning says so.
  • It works where other clients fail.The platform's firewall blocks Google's own client, and any request that mentions Western Sahara. undata routes around both.

// 05 — in Claude

Ask Claude, and it uses undata

undata is also an MCP connector. Add it to Claude Desktop or Claude Code and ask in plain words: "Which least developed countries are on track to bring maternal mortality below 70 by 2030? Show me a chart." Claude finds the indicator, runs the UN Statistics Division's progress method and answers with the table, the chart, the caveats and the sources, all from the same tested functions on this page.

Claude Desktop

Install uv, then in Settings → Developer → Edit Config add:

{
  "mcpServers": {
    "undata": {
      "command": "uvx",
      "args": ["--from", "undata[mcp]",
               "undata-mcp"]
    }
  }
}

Claude Code

One command:

claude mcp add undata -- \
  uvx --from "undata[mcp]" undata-mcp

Other MCP clients: pip install "undata[mcp]", then run undata-mcp (stdio) or undata-mcp --http.

What Claude can do

Fourteen read-only tools: find indicators by words or SDG number, list countries and groups, fetch data, and run progress, profile, gap and benchmark analyses, with charts. No account, no key.
