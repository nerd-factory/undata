// a nerd lab experiment · unofficial

UN data in Python, without the guessing.

undata is a Python client for the UN System Data Commons: statistics from 26 UN System entities in one knowledge graph, no API key required. It is built around the platform's habits that make ordinary client code quietly wrong.

pip install "git+https://github.com/nerd-factory/undata"

Pre-alpha, and honest about it. Every block marked works today is a script in examples/, and the output under it is what that script printed against the live API on 12 October 2026. Blocks marked from 0.1 show the planned API in the plan; they do not run yet.

// 01 — why it exists

Four things the platform will not tell you

Each was found by calling the live API, and each is pinned by a test that runs every night, so the package notices when the platform changes.

  • 403

    Google's official datacommons-client cannot fetch data from data.un.org: the firewall blocks any POST body containing "select", and that client always POSTs. undata uses GET.

  • USA

    Ask the search box about child mortality in Bengal and it answers about the United States, under a title that does not say so.

  • 20 / 210

    20 countries report the conflict death rate; 210 report GDP per capita. The other 190 are absent from the response, not zero.

  • #23

    Search ranks an older copy of the SDG data first. The UN's own maternal mortality series is result 23 of 65, and its latest figure is three years newer.

01 · for analysts and report writers

Compare countries on one indicator

Five South Asian countries on the Human Development Index, each at its latest year. India and Bangladesh tie at 0.685. That is the data, not a rounding bug.

works todayexamples/01_compare_countries.py
"""Compare South Asian countries on the Human Development Index."""

import undata
from undata import _endpoints as api

HDI = "undata/undphdro/HDI_hdi"
COUNTRIES = ["country/BGD", "country/IND", "country/LKA", "country/NPL", "country/PAK"]

with undata.Transport() as t:
    body = api.observation(t, HDI, entities=COUNTRIES)

rows = []
for place, block in body["byVariable"][HDI]["byEntity"].items():
    latest = block["orderedFacets"][0]["observations"][0]
    rows.append((latest["value"], place, latest["date"]))

for value, place, year in sorted(rows, reverse=True):
    print(f"{place:<12} {year}  {value:.3f}")

02 · for dashboards and regional reports

A whole region in one request

A containment expression is evaluated inside the graph, so one call replaces a loop over 54 country codes. The script also counts which year each value is from, because "latest" means each country's own latest. Here every country happens to report 2024. Often they do not.

works todayexamples/02_whole_region.py
"""Every African country in one request, and a check on which year each value is from."""

from collections import Counter

import undata
from undata import _endpoints as api

ELECTRICITY = "undata/sdg/EG_ACS_ELEC"  # % of population with access to electricity

with undata.Transport() as t:
    body = api.observation(t, ELECTRICITY, entity_expression=undata.child_countries_of("africa"))

latest = {
    place: block["orderedFacets"][0]["observations"][0]
    for place, block in body["byVariable"][ELECTRICITY]["byEntity"].items()
    if block.get("orderedFacets")
}
print(len(latest), "countries")
print("years:", dict(Counter(obs["date"] for obs in latest.values())))
for place, obs in sorted(latest.items(), key=lambda item: item[1]["value"])[:3]:
    print(f"{place:<12} {obs['date']}  {obs['value']}%")
outputlive, 12 October 2026
54 countries
years: {'2024': 54}
country/SSD  2024  5.4%
country/TCD  2024  13.4%
country/MWI  2024  15.6%

03 · for researchers, and anyone about to draw a scatter

Count who reports before you join

Norway is not zero on conflict deaths. It is not in the response at all, because a country with no conflict files no conflict-death return. Join these two indicators and every peaceful country drops out before the chart is drawn, so the scatter answers a different question from the one you asked.

works todayexamples/03_missing_is_not_zero.py
"""Count who reports before you join two indicators. Absent is not zero."""

import undata
from undata import _endpoints as api

GDP_PER_CAPITA = "undata/unicef/SPP_GDPPC"
CONFLICT_DEATH_RATE = "undata/sdg/VC_DTH_TOTR"  # SDG 16.1.2, per 100,000
EVERY_COUNTRY = undata.child_countries_of("Earth")


def reporting(t: undata.Transport, variable: str) -> set[str]:
    body = api.observation(t, variable, entity_expression=EVERY_COUNTRY)
    by_entity = body["byVariable"][variable]["byEntity"]
    return {place for place, block in by_entity.items() if block.get("orderedFacets")}


with undata.Transport() as t:
    gdp = reporting(t, GDP_PER_CAPITA)
    conflict = reporting(t, CONFLICT_DEATH_RATE)

print("GDP per capita:     ", len(gdp), "countries")
print("Conflict death rate:", len(conflict), "countries")
print("Both:               ", len(gdp & conflict))
print("Norway in the conflict series?", "country/NOR" in conflict)
outputlive, 12 October 2026
GDP per capita:      210 countries
Conflict death rate: 20 countries
Both:                20
Norway in the conflict series? False
from 0.1 · planned
obs = un.data.fetch(["undata/unicef/SPP_GDPPC", "undata/sdg/VC_DTH_TOTR"], places="world")
obs.missing  # every absent place/variable pair, listed rather than hidden

04 · for SDG reporting officers

From an SDG target to data you can fetch

Mandates name targets, not variable codes. The SDG framework is a branch of the graph you can walk exactly: target 16.1, then indicator 16.1.2, then six groups, one of which is a per-100,000 rate you might not have known existed.

works todayexamples/04_sdg_target.py
"""From an SDG target to variables you can fetch, by walking the framework."""

import undata
from undata import _endpoints as api


def children(t: undata.Transport, node: str) -> list[dict[str, str]]:
    body = api.node(t, node, "<-specializationOf")
    return body["data"][node]["arcs"]["specializationOf"]["nodes"]


with undata.Transport() as t:
    for indicator in children(t, "undata/g/sdgf/target-16-1"):
        print(indicator["name"][:72])
    print()
    for group in children(t, "undata/g/sdgf/ind-16-1-2"):
        print(f"{group['dcid']:<26} {group['name']}")

05 · for anyone who uses, or builds on, data.un.org's search

Check what the search box decided

The natural-language resolver always commits to a place. Given one it does not recognise, it substitutes another without saying so. The chart it draws is titled "Total Child Mortality, by Age" either way.

works todayexamples/05_check_the_resolver.py
"""See which place the site's search box decided you meant, before trusting its chart."""

import undata
from undata import _endpoints as api

with undata.Transport() as t:
    for question in ["child mortality in Bengal", "child mortality in Bangladesh"]:
        place = api.detect_and_fulfill(t, question)["place"]
        print(f"{question!r:<34} -> {place['dcid']}  ({place['name']})")
outputlive, 12 October 2026
'child mortality in Bengal'        -> country/USA  (United States of America)
'child mortality in Bangladesh'    -> country/BGD  (Bangladesh)
from 0.1 · planned
r = un.ask("child mortality in Bengal")
r.place_was_inferred  # True, and an InferredPlaceWarning is raised

06 · for pipelines that start from a spreadsheet of country names

Turn names into identifiers

Official names resolve, accents and apostrophes included. "Bengal" resolves to nothing, which is the honest answer and the one the search box does not give.

works todayexamples/06_names_to_ids.py
"""Turn place names into identifiers, and notice when a name matches nothing."""

import undata
from undata import _endpoints as api

NAMES = ["Bangladesh", "Viet Nam", "Côte d'Ivoire", "Bengal"]

with undata.Transport() as t:
    body = api.resolve(t, NAMES)

for entity in body["entities"]:
    candidates = [c["dcid"] for c in entity.get("candidates", [])]
    print(f"{entity['node']:<15} {candidates or 'no match'}")
outputlive, 12 October 2026
Bangladesh      ['country/BGD']
Viet Nam        ['country/VNM']
Côte d'Ivoire   ['country/CIV']
Bengal          no match

07 · for anyone who cites a number

Know whose series you are publishing

Search ranks Data Commons' own older copy of the SDG database first. Both copies link to the same UN portal, so nothing on the surface tells them apart, but they disagree on the year and the value. The source field does tell them apart.

works todayexamples/07_two_series_one_name.py
"""Search hands you a series. Check whose it is before you publish a number from it."""

import undata
from undata import _endpoints as api

with undata.Transport() as t:
    hits = [hit["dcid"] for hit in api.stat_var_search(t, "maternal mortality")["statVars"]]
    un_series = "undata/sdg/SH_STA_MORT.SEX--F"
    print("top hit:      ", hits[0])
    print("UN series at: ", f"#{hits.index(un_series) + 1} of {len(hits)}")
    print()

    body = api.series(t, [hits[0], un_series], ["country/BGD"])

for variable, by_entity in body["data"].items():
    block = by_entity["country/BGD"]
    last = block["series"][-1]
    source = body["facets"][block["facet"]]["provenanceId"]
    print(f"{variable:<30} {last['date']}  {last['value']:.1f}  source: {source}")
outputlive, 12 October 2026
top hit:       sdg/SH_STA_MORT.SEX--F
UN series at:  #23 of 65

sdg/SH_STA_MORT.SEX--F         2020  123.0  source: dc/base/UN_SDG
undata/sdg/SH_STA_MORT.SEX--F  2023  115.1  source: undata/p/SDG

08 · for charts

A full time series for a trend line

Every year for every variable and place pair, in one call. Bangladesh's maternal mortality ratio fell by more than three quarters between 2000 and 2023.

works todayexamples/08_time_series.py
"""A full time series per country, for a trend line."""

import undata
from undata import _endpoints as api

MMR = "undata/sdg/SH_STA_MORT.SEX--F"  # maternal deaths per 100,000 live births

with undata.Transport() as t:
    body = api.series(t, MMR, ["country/BGD", "country/NOR"])

for place, block in body["data"][MMR].items():
    first, last = block["series"][0], block["series"][-1]
    print(
        f"{place:<12} {len(block['series'])} years   "
        f"{first['date']}: {first['value']:.1f}  ->  {last['date']}: {last['value']:.1f}"
    )
outputlive, 12 October 2026
country/BGD  24 years   2000: 522.7  ->  2023: 115.1
country/NOR  24 years   2000: 5.4  ->  2023: 1.3

un.data.fetch("undata/sdg/SH_STA_MORT.SEX--F", places=["BGD", "NOR"], time="all").to_pandas()

09 · for developers

Read and build identifiers

The identifier grammar, offline. One warning it encodes: the "unknown" age band is a slice of its own, so adding up the named age bands will not reproduce the total.

works todayexamples/09_identifiers.py
"""Read and build variable identifiers. No network needed."""

import undata

dcid = "undata/sdg/VC_DTH_TOTN.AGE--Y0T17__SEX--F"
parsed = undata.parse_dcid(dcid)
assert parsed is not None
print(parsed.agency_label, "|", parsed.code, "|", [str(d) for d in parsed.dimensions])
print(undata.describe_dcid(dcid))

# The same slice always gets the same identifier, whatever order you pass dimensions in.
print(undata.build_dcid("undata/sdg/VC_DTH_TOTN", {"SEX": "F", "AGE": "Y0T17"}))

# The "unknown" age band is its own slice. The named bands do not sum to the total.
print(undata.describe_dcid("undata/sdg/VC_DTH_TOTN.AGE--_U__SEX--_U"))
outputoffline
Global SDG Indicators Database | VC_DTH_TOTN | ['AGE--Y0T17', 'SEX--F']
Global SDG Indicators Database · VC_DTH_TOTN [AGE=Y0T17, SEX=F]
undata/sdg/VC_DTH_TOTN.AGE--Y0T17__SEX--F
Global SDG Indicators Database · VC_DTH_TOTN [AGE=_U, SEX=_U]

10 · for notebooks and data teams

A tidy DataFrame with sources

The flattening everyone writes today, with the empty-series branch written first and the source carried onto every row. In 0.1 the whole script becomes one line.

works todayexamples/10_to_pandas.py
"""A tidy pandas DataFrame with the source on every row. Needs: pip install pandas."""

import pandas as pd

import undata
from undata import _endpoints as api

VARIABLES = ["undata/sdg/SH_STA_MORT.SEX--F", "undata/sdg/EG_ACS_ELEC"]
PLACES = ["country/BGD", "country/NPL", "country/SSD"]

with undata.Transport() as t:
    body = api.series(t, VARIABLES, PLACES)

rows = []
for variable, by_entity in body["data"].items():
    for place in PLACES:
        block = by_entity.get(place, {})
        if not block.get("series"):
            print("no data:", variable, place)  # absent, not zero
            continue
        facet = body["facets"][block["facet"]]
        rows.extend(
            {
                "variable": variable,
                "place": place,
                "date": obs["date"],
                "value": obs["value"],
                "source": facet["provenanceId"],
                "unit": facet.get("unitDisplayName"),
                "provenance_url": facet.get("provenanceUrl"),
            }
            for obs in block["series"]
        )

df = pd.DataFrame(rows)
print(df.groupby(["variable", "place"])["date"].agg(["min", "max", "count"]))
