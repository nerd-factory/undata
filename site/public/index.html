// a nerd lab experiment · unofficial

UN data in Python, without the guessing.

Type a country's name, get a table. undata is a Python package for the UN System Data Commons, which holds statistics from 26 UN System entities. It is written for colleagues who need numbers for a report, not a course in APIs.

pip install "git+https://github.com/nerd-factory/undata"

Alpha. It works today; install it from GitHub as above until it reaches PyPI. Every output on this page is real: each example below is a script in examples/, run against the live platform on 13 October 2026, and the same scripts run again every night.

// 01 — start

Three lines to a spreadsheet

Open a notebook (Jupyter, VS Code or Google Colab), install the package, and run this. You get an Excel file with the numbers on one sheet and a citation for each source on the next.

python
import undata as un

table = un.get("undata/sdg/SH_STA_MORT.SEX--F", ["Bangladesh", "Viet Nam"])
un.save(table, "maternal-mortality.xlsx")

Don't know the indicator's id? un.search("maternal mortality") lists matching indicators with their names; copy the id from the first column. In Colab, install with !pip install "git+https://github.com/nerd-factory/undata".

// 02 — functions

Everything on one screen

Wherever a function asks for countries you can write names the way you would in an email ("Viet Nam", "Vietnam", "VNM"), a list of them, or a region such as "Southern Asia" or "Africa". Every function explains itself: help(un.get).

functionwhat it does
un.search("words")Find indicators by what they measure. UN collections only, best match first.
un.about(indicator)What an indicator is, whose it is, its unit, and which years it covers.
un.get(indicator, countries, years)The numbers: one row per country and year, with unit and source.
un.latest(indicator, countries)Each country's most recent value, and a warning if those years differ.
un.countries(region)
un.regions()		The country and region names it knows, with UN names and ISO codes.
un.sdg.goals()
un.sdg.targets(16)
un.sdg.indicators("16.1")
un.sdg.series("16.1.2")		Walk from an SDG goal down to indicators you can fetch.
un.ask("a question")See what data.un.org's search box decided, including whether it guessed the place.
un.save(table, "file.xlsx")
un.cite(table)		Save to Excel or CSV with sources; write citations for a report.

// 03 — what it does for you

The careful parts are built in

Each of these was found by calling the live platform, and each is checked by a test that runs every night.

  • It never guesses a place.data.un.org's search box answers a question about "Bengal" with figures for the United States. undata stops and says it does not know "Bengal".
  • Gaps are named, never zero.Only 20 countries report the conflict death rate. The rest are listed in a warning, not charted as peaceful zeros.
  • UN names in, UN names out.Tables say Türkiye, Viet Nam and Côte d'Ivoire, ready for a UN document, whatever spelling you typed.
  • The source is on every row.The same statistic can come from three agencies with different numbers. The source column says whose you have.
  • Mixed years are flagged."Latest" means each country's own latest year. When those differ, a warning says so.
  • It works where other clients fail.The platform's firewall blocks Google's own client, and any request that mentions Western Sahara. undata routes around both.

01 · for anyone new to this

Your first table

Search for an indicator in plain words, copy its id, and ask for the countries you need. The result is an ordinary table: sort it, filter it, chart it, or save it.

exampleexamples/01_first_table.py
"""Your first table: find an indicator by name, then get it for two countries."""

import undata as un

# 1. Find the indicator. Copy its id from the "indicator" column.
print(un.search("maternal mortality").head(3).to_string(index=False))

# 2. Get it. Country names work as you would write them.
table = un.get("undata/sdg/SH_STA_MORT.SEX--F", ["Bangladesh", "Viet Nam"], years=(2020, 2023))
print(table[["country", "year", "value", "unit"]].to_string(index=False))

02 · for analysts and report writers

Compare the countries of a region

A region name stands for every country in it. Here, the Human Development Index across Southern Asia, each country at its latest year. Note that India and Bangladesh tie: that is the data, not a rounding error.

exampleexamples/02_compare_countries.py
"""Compare the countries of a region on one indicator, each at its latest year."""

import undata as un

table = un.latest("undata/undphdro/HDI_hdi", "Southern Asia")

ranked = table.sort_values("value", ascending=False)
print(ranked[["country", "year", "value"]].to_string(index=False))

03 · for dashboards and regional reports

A whole continent in one line

Access to electricity for every country in Africa. This request used to fail outright: the platform's firewall refuses any request that mentions Western Sahara, and undata now asks in a way the firewall accepts.

exampleexamples/03_whole_region.py
"""A whole continent in one line. Regions stand for every country in them."""

import undata as un

table = un.latest("undata/sdg/EG_ACS_ELEC", "Africa")  # % with access to electricity

print(len(table), "countries, latest years:", sorted(table["year"].unique().tolist()))
print(table.nsmallest(3, "value")[["country", "year", "value", "unit"]].to_string(index=False))

04 · for SDG reporting officers

From an SDG target to the numbers

Mandates name targets, not data codes. Start from the target, list its indicators, pick the series that reports the one you need, and fetch it.

exampleexamples/04_sdg_target.py
"""From an SDG target your mandate names, to the numbers."""

import undata as un

print(un.sdg.indicators("16.1").to_string(index=False))

series = un.sdg.series("16.1.2")
print(series[series["total"]][["indicator", "name"]].to_string(index=False))

rates = un.latest("undata/sdg/VC_DTH_TOTR", ["Ukraine", "Sudan", "Myanmar"])
print(rates[["country", "year", "value"]].to_string(index=False))

05 · for anyone about to draw a chart

Gaps are named, never zero

Norway and Japan have no conflict death rate on the platform, because a country without conflict files no conflict-death return. They are not zero. undata leaves them out of the table and says so, so a chart cannot quietly show them as peaceful zeros.

exampleexamples/05_missing_data.py
"""Countries without data are named, never turned into zeros."""

import undata as un

table = un.latest("undata/sdg/VC_DTH_TOTR", ["Ukraine", "Norway", "Japan", "Mali"])

print(table[["country", "year", "value"]].to_string(index=False))
print("No data for:", [row["country"] for row in table.attrs["missing"]])

06 · for everyone

Names the way you write them

UN names, everyday names and ISO codes all work, and tables always use the UN name. A name it does not know stops with suggestions. It never becomes some other country.

exampleexamples/06_names_and_regions.py
"""Names, UN names, codes and regions all work. Unknown names are never guessed."""

import undata as un

print(un.countries("Western Africa").head(4).to_string(index=False))

for name in ["Vietnam", "Türkiye", "Ivory Coast", "COD", "Bengal"]:
    try:
        print(f"{name!r:<14} ->", un.places.resolve(name).name)
    except un.PlaceNotFoundError as error:
        print(f"{name!r:<14} -> {error}")

07 · for anyone who uses data.un.org's search box

Check what the search box decided

The search box always answers about some place. When it does not recognise yours, it picks one and titles the chart as if nothing happened. un.ask shows its choice and warns when it was a guess.

exampleexamples/07_check_the_search_box.py
"""See what data.un.org's search box decided, before you trust its chart."""

import undata as un

answer = un.ask("child mortality in Bengal")
print(answer.place, "| guessed:", answer.place_was_guessed)

answer = un.ask("child mortality in Bangladesh")
print(answer.place, "| guessed:", answer.place_was_guessed)

08 · for anyone who cites a number

Know whose number you are using

Bangladesh's maternal mortality ratio for 2023, as published by three UN entities. Two agree; one does not. Quote the source along with the figure.

exampleexamples/08_know_your_source.py
"""One statistic, three agencies. The source column says whose number you are using."""

import undata as un

MATERNAL_MORTALITY_RATIO = [
    "undata/sdg/SH_STA_MORT.SEX--F",  # Global SDG Indicators Database
    "undata/unicef/MNCH_MMR.SEX--F",  # UNICEF
    "undata/undphdro/GII_mmr.SEX--F",  # UNDP Human Development Report Office
]
table = un.latest(MATERNAL_MORTALITY_RATIO, "Bangladesh")

print(table[["source", "year", "value"]].to_string(index=False))

09 · for reports and briefings

Save to Excel and cite it

The Excel file has the data on one sheet, a citation for every source on the next, and, when some countries had no data, a third sheet listing them. The citation credits the agency that produced the figures.

exampleexamples/09_save_and_cite.py
"""Save to Excel with a sheet of citations, and cite the data in a report."""

import undata as un

table = un.get("undata/sdg/SH_STA_MORT.SEX--F", "Southern Asia", years=(2015, 2023))

un.save(table, "maternal-mortality.xlsx")  # sheets: data, sources
print(un.cite(table))

// 05 — install

Getting it

On your computer

Needs Python 3.11 or newer. Comes with pandas and Excel support.

pip install "git+https://github.com/nerd-factory/undata"

In Google Colab

Nothing to install on your machine. Run this in the first cell.

!pip install "git+https://github.com/nerd-factory/undata"

Run these examples

With uv, which fetches the right Python itself.

git clone https://github.com/nerd-factory/undata
cd undata
uv run python examples/01_first_table.py

undata is a Nerd Lab experiment. Unofficial: not affiliated with or endorsed by the United Nations. The data belongs to the agencies that publish it, under the UN Data Commons terms of use.

Most of what the package knows about the platform was found while writing the UN Data Commons Field Guide.
