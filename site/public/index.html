// a nerd lab experiment · unofficial

UN data in Python, without the guessing.

Type a country's name, get a table with its source on every row. undata is a Python package for the UN System Data Commons, which holds statistics from 26 UN System entities, and it is written for colleagues who need numbers for a report, not a course in APIs.

pip install undata

Try it in your browser, no install · Watch it work: six two-minute videos — a sourced spreadsheet, SDG progress by the UN method, a country in context, who is left behind, the safeguards, and an AI assistant that cites its numbers.

Everything on this page is real. Each use case below is a script in examples/. The output, the charts and the sentence for your report are what those scripts produced against the live platform on 14 October 2026, and the same scripts run again every night.

01Resident Coordinator's Officebriefing note

A briefing note before a country visit

"The RC is in N'Djamena on Monday. I need one page: electricity, child mortality and schooling in Chad, compared with the other Sahel countries."

The ask

The code

pythonexamples/01_country_briefing.py
"""Briefing note: Chad against its Sahel neighbours, in one table and one sentence."""

import undata as un

SAHEL = ["Chad", "Niger", "Mali", "Burkina Faso", "Mauritania", "Sudan"]
MEASURES = {
    "electricity %": "undata/sdg/EG_ACS_ELEC",
    "under-5 deaths per 1,000": "undata/unicef/CME_MR.AGE--Y0T4",
    "primary completion %": "undata/sdg/SE_TOT_CPLR.EDUCATION_LEVEL--ISCED11_1",
}

# One row per country, a value and a year per measure.
brief = un.compare(MEASURES, SAHEL).set_index("country")
print(brief.drop(columns="iso3").round(1).to_string(), "\n")

# The sentence for the note, worked out from the numbers rather than typed in.
RANK = {1: "", 2: "second-", 3: "third-", 4: "fourth-", 5: "fifth-", 6: "sixth-"}
chad = brief.loc["Chad"]
power_rank = int(brief["electricity %"].rank()["Chad"])  # 1 = the lowest
deaths_rank = int(brief["under-5 deaths per 1,000"].rank(ascending=False)["Chad"])  # 1 = highest
print(
    f"In {chad['electricity % year']}, {chad['electricity %']:.0f}% of people in Chad had "
    f"electricity, the {RANK[power_rank]}lowest of the six Sahel countries compared, and "
    f"{chad['under-5 deaths per 1,000']:.0f} of every 1,000 children died before their fifth "
    f"birthday, the {RANK[deaths_rank]}highest."
)

02SDG reportingprogress report

Is a target moving?

"For the regional SDG progress report: has maternal mortality in Southern Asia fallen since 2015, and where is it already below 70?"

The ask

The code

pythonexamples/02_sdg_progress.py
"""SDG 3.1: has maternal mortality fallen since 2015, and where is it below 70?"""

import undata as un

# The SDG indicator number works directly: 3.1.1 is the maternal mortality ratio.
change = un.change("3.1.1", "Southern Asia", 2015, 2023).sort_values("end_value")
print(change[["country", "start_value", "end_value", "change_pct"]].round(0).to_string(index=False))

# The regional and world figures, as published, to set the countries against.
print(
    un.totals("3.1.1", ["Southern Asia", "World"], years=2023)[["country", "value"]].round(0), "\n"
)

fell = int((change["change"] < 0).sum())
fell_in = f"all {fell}" if fell == len(change) else f"{fell} of the {len(change)}"
below = change.loc[change["end_value"] < 70, "country"].tolist()
print(
    f"Between 2015 and 2023, maternal mortality fell in {fell_in} countries of Southern Asia. "
    f"{len(below)} were below 70 deaths per 100,000 live births in 2023 ({', '.join(below)}), "
    "the level Target 3.1 sets for the world as a whole."
)

The code

"""Women in parliament: who has passed 30%, and who has reached parity?"""

import undata as un

SEATS = "undata/sdg/SG_GEN_PARL.SEX--F"  # % of seats held by women, SDG 5.5.1

table = un.latest(SEATS, "Eastern Africa").sort_values("value", ascending=False)
print(table[["country", "year", "value"]].round(1).to_string(index=False), "\n")

thirty = table[table["value"] >= 30]
parity = table[table["value"] >= 50]
print(
    f"{len(thirty)} of the {len(table)} Eastern African parliaments with data have at least "
    f"30% women. {', '.join(parity['country'])} passed parity, with "
    f"{parity['value'].iloc[0]:.0f}% of seats held by women."

04Humanitarian coordinationsituation overview

Refugees: count or share?

"Which countries in the region have the most people living as refugees abroad, and does the picture change once you account for population?"

The ask

The code

pythonexamples/04_refugees.py
"""Refugees by country of origin: the most in number is not the most per person."""

import undata as un

NUMBER = "undata/unicef/MG_RFGS_CNTRY_ORIGIN"  # refugees, by country of origin
PER_100K = "undata/sdg/SM_POP_REFG_OR"  # the same, per 100,000 population

# A region and a country together: Sudan is in Northern Africa in the UN's regions.
table = un.latest([NUMBER, PER_100K], ["Eastern Africa", "Sudan"])

for indicator, label in [(NUMBER, "Most refugees"), (PER_100K, "Most per 100,000 people")]:
    top = table[table["indicator"] == indicator].nlargest(5, "value")
    print(label)
    print(top[["country", "year", "value"]].to_string(index=False), "\n")

number = table[table["indicator"] == NUMBER].set_index("country")["value"]
rate = table[table["indicator"] == PER_100K].set_index("country")["value"]
print(
    f"{number.idxmax()} has the most refugees abroad ({number.max() / 1e6:.1f} million), but "
    f"relative to population {rate.idxmax()} is hit hardest: {rate.max():,.0f} refugees "
    f"for every 100,000 people, about one in {100_000 / rate.max():.0f}."
)

05Peace and securityCouncil briefing

Conflict deaths in context

"For the briefing: where are conflict-related deaths highest, and how do they compare with ordinary homicide in the same countries?"

The ask

The code

pythonexamples/05_conflict_and_homicide.py
"""Conflict deaths in context: who reports them, and how they compare with homicide."""

import undata as un

INDICATORS = {
    "conflict": "undata/sdg/VC_DTH_TOTR",  # conflict-related deaths per 100,000, SDG 16.1.2
    "homicide": "undata/sdg/VC_IHR_PSRC",  # intentional homicide per 100,000, SDG 16.1.1
}

# Ask for the whole world. The warning says how many countries have both: few.
table = un.compare(INDICATORS, "World")
reporting = table[table["conflict"].notna()].sort_values("conflict", ascending=False)
print(reporting[["country", "conflict", "homicide"]].round(1).to_string(index=False), "\n")

higher = reporting.loc[reporting["conflict"] > reporting["homicide"], "country"].tolist()
print(
    f"Only {len(reporting)} countries report conflict-related deaths. In {len(higher)} of "
    f"them, conflict killed more people per 100,000 than homicide: {', '.join(higher)}."
)

06Statistics focal pointquoting a figure

When agencies disagree

"Two reports quote different maternal mortality figures for Bangladesh. Which is right, and what should we cite?"

The ask

The code

pythonexamples/06_agencies_disagree.py
"""One statistic, three agencies. Quote one figure, and name whose it is."""

import undata as un

MATERNAL_MORTALITY_RATIO = [
    "undata/sdg/SH_STA_MORT.SEX--F",  # Global SDG Indicators Database
    "undata/unicef/MNCH_MMR.SEX--F",  # UNICEF
    "undata/undphdro/GII_mmr.SEX--F",  # UNDP Human Development Report Office
]
table = un.latest(MATERNAL_MORTALITY_RATIO, "Bangladesh")
print(table[["source", "year", "value"]].round(1).to_string(index=False), "\n")

low, high = table["value"].min(), table["value"].max()
odd = table.loc[table["value"].idxmax(), "source"]
print(
    f"For Bangladesh in {table['year'].max()}, the three sources give {low:.0f} to {high:.0f} "
    f"maternal deaths per 100,000 live births; {odd} is the outlier. A gap of "
    f"{(high / low - 1) * 100:.0f}% is enough to change a headline, so cite the source."
)

"""Refresh the numbers behind a dashboard. Schedule this file; nobody has to run it."""

from datetime import date

import undata as un

INDICATORS = [
    "undata/sdg/EG_ACS_ELEC",
    "undata/unicef/CME_MR.AGE--Y0T4",

table = un.get(INDICATORS, "Southern Asia", years=(2015, date.today().year))
un.save(table, "dashboard-data.csv")  # Power BI, Tableau or Excel reads this file

print(
    f"{date.today()}: wrote {len(table)} rows for {table['country'].nunique()} countries, "
    f"{table['year'].min()} to {table['year'].max()}, to dashboard-data.csv"
)

10SDG reportingprogress report

Who is on track for 2030?

"For the LDC chapter of the SDG progress report: which least developed countries are on track to bring maternal mortality below 70 by 2030, using the same method as the UN's own report?"

The ask

The code

pythonexamples/10_sdg_progress_ldcs.py
"""Are the least developed countries on track to cut maternal deaths by 2030?"""

import undata as un

# SDG 3.1.1, lower is better; 70 per 100,000 live births is the Target 3.1 level.
table = un.progress("3.1.1", "LDCs", better="lower", target=70)

// 04 — what it does for you

The careful parts are built in

Each of these was found by calling the live platform, and each is checked by a test that runs every night.

  • It never guesses a place.data.un.org's search box answers a question about "Bengal" with figures for the United States. undata stops and says it does not know "Bengal".
  • Gaps are named, never zero.Countries without data are listed in a warning and on their own Excel sheet, never charted as zeros.
  • UN names in, UN names out.Tables say Türkiye, Viet Nam and Côte d'Ivoire, ready for a UN document, whatever spelling you typed.
  • The source is on every row.The same statistic can come from several agencies with different numbers. The source column says whose you have.
  • Mixed years are flagged."Latest" means each country's own latest year. When those differ, a warning says so.
  • It works where other clients fail.The platform's firewall blocks Google's own client, and any request that mentions Western Sahara. undata routes around both.
